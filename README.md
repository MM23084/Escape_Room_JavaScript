# 🔓 Escape Room JavaScript

Un juego interactivo de escape room desarrollado con tecnologías web modernas. Resuelve acertijos, encuentra pistas y escapa antes de que se acabe el tiempo.

## 🎮 Características

- 🧩 Múltiples acertijos y desafíos
- ⏱️ Sistema de temporizador
- 💾 Guardado de progreso
- 🎨 Interfaz visual atractiva
- 🎯 Diferentes niveles de dificultad
- 📱 Diseño responsivo

## 🛠️ Tecnologías

- **JavaScript** (47.3%) - Lógica del juego
- **HTML** (27.6%) - Estructura
- **CSS** (25.1%) - Estilos y diseño

## 🚀 Cómo Usar

1. **Clona el repositorio**
   ```bash
   git clone https://github.com/MM23084/Escape_Room_JavaScript.git
   cd Escape_Room_JavaScript
   ```

2. **Abre el juego**
   - Simplemente abre el archivo `index.html` en tu navegador favorito
   - No requiere instalación adicional

3. **¡Comienza el juego!**
   - Lee las pistas cuidadosamente
   - Haz clic en objetos interactivos
   - Resuelve acertijos para avanzar
   - ¡Intenta escapar antes de que se acabe el tiempo!

## 📂 Estructura del Proyecto

```
Escape_Room_JavaScript/
├── index.html          # Archivo principal
├── style.css           # Estilos
├── script.js           # Lógica del juego
└── assets/             # Recursos (imágenes, etc.)
```

## 🎯 Objetivos del Juego

- Encuentra todas las pistas ocultas
- Resuelve los acertijos
- Desbloquea la puerta de escape
- Completa el nivel antes de que expire el tiempo

## 📋 Requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- JavaScript habilitado
